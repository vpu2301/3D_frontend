# Werkzeuge (FE7 §1)

Route `/telephony/settings/tools`. Components `src/pages/telephony/_components/settings/tools/*` (`ToolsView`, `ToolRow`, `TierChip`, `WhyNotDialog`, `ToolTimelineView`); data `src/lib/api/owner/tools.ts`; labels `src/content/tool-labels.ts`; namespace `voice-tools`. Bound to E1 as shipped.

- **List** — `GET /api/voice/tool-policy` → `{tools:[{tool, tier R|W|X, source, latency_budget_ms, enabled, approval_override "", verbal, user, off, reason, has_row, row_tier, server}], servers, cap}`. The owner sees a friendly name and one sentence from the curated map (raw name small; unknown tools humanised), the tier in owner words (`Nur lesen` / `Schreiben` / `Nicht am Telefon`), `Standard` for the backend's default inbound set (`google__check_freebusy`, `business_profile_lookup`, `google__create_event`, `send_owner_message`), and `Von Ihrer Betreuung deaktiviert` for disabled policy rows. **X rows render no switch at all**; "Warum?" opens the engine's own `reason` (tested).
- **Opt-in per profile** — `receptionist.tools` on the active profile (max 20): a toggle writes `PUT /api/voice/profiles/{id} {data: {...active, receptionist:{...,tools}}, note, activate:true}` — a new, activated version, visible in the profile history. The profile editor passes the `receptionist` block through untouched (`draftSchema.receptionist`).
- **Nur mit Freigabe** — `PUT /api/voice/tool-policy/{tool} {tier, enabled, latency_budget_ms, approval_override:"user"|""}`. Turning a W tool on sets `user` first (decision §12: yes, with approval on by default). The server's 422 sentence (widening a tier) is shown verbatim.
- **Cap** — `n von 40` counts the tools on for this profile; the per-profile limit (20) is enforced client-side with the same message the validator would give.
- **Vorschläge** — read-only tools in the calendar/contacts/knowledge groups that are not on yet, one-click enable; computed in the browser (badge) until the backend heuristic is exposed (ask).
- **Aktionen tab** (call detail) de-badged: `tool_timeline` (`outcome ok|denied|deferred`, `approval`, `reason`, `ms`) → owner name, `erledigt` / `abgelehnt` / `fehlgeschlagen` (`tool_error`, `tool_timeout`) / `fehlgeschlagen – später nachgeholt`, `von Ihnen freigegeben` / `vom Anrufer bestätigt`, the masked `output_summary`. Older backends without `tool_timeline` get the same rows derived from `actions`. `?debug` keeps the engine timeline underneath.
- Founders reach the full tier table in the console (`/telephony/policies`).
