# Branchenvorlagen (FE9 §2)

Route `/telephony/settings/profile/templates` (entry links on the profile editor header and the wizard's welcome step). Components `src/pages/telephony/_components/settings/templates/TemplatesView.tsx` (`TemplateCards`, review with `DiffView`); data `src/lib/api/owner/templates.ts`; content `src/content/templates.ts`; namespace `voice-templates`.

Seven packs — Steuerkanzlei, Rechtsanwalt, Arztpraxis, Handwerk, Hausverwaltung, IT-Systemhaus, Hotel/Gastro — each with a persona note, greeting tail, FAQ, hours defaults, after-hours message, emergency keywords, appointment duration, a rules-pack id, tool suggestions, KPI labels and follow-up templates, versioned. `GET /api/voice/templates` is asked first; today the content ships in the app (badge G1) and never overwrites owner edits: applying builds `applyPack(current, pack, selectedFields)`, shows the FE3 diff, and saves a profile version with `activate: false` (tested + e2e) — the owner activates in the editor. The pack's rules are installed through D2's pack route and switched off one by one (FE5 rule; e2e asserts the PATCHes). When `POST /api/voice/templates/{slug}/apply` exists the server draft is used instead.
