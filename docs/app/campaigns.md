# Kampagnen (FE8 §3, behind `capabilities.campaigns`)

Route `/telephony/campaigns`, `/new`, `/:id`. Components `src/pages/telephony/_components/campaigns/*` (`CampaignsView`, `CampaignCard` with `ProgressBars` + `LegalChip`, `CampaignWizard` with `LegalBasisStep`, `ColumnMapper`, `ScrubResult`, `WindowPacing`, `CampaignDetail`, `CampaignReminders`); data `src/lib/api/owner/campaigns.ts`; namespace `voice-campaigns`. The nav item disappears when the backend reports `capabilities.campaigns=false`.

F1/F2 have no HTTP surface. Agreed routes (all badge on 404 with one F1 banner): `GET/POST /api/voice/campaigns`, `GET …/{id}`, `PUT …/{id}/steps/legal|script|window`, `POST …/{id}/contacts/import` (multipart CSV + mapping JSON, XHR progress → scrub report), `GET …/{id}/contacts?page=`, `POST …/{id}/validate` → `{ok, checks:[{key, ok, reason}]}`, `POST …/{id}/start|pause|resume|stop`, `GET …/{id}/outcomes.csv?masked=1`, `GET/PUT /api/voice/campaigns/reminders`.

Wizard order (F1 §3.5): Art → **Rechtsgrundlage** (plain-German § 7 UWG per option; `canProceedLegal()` refuses marketing consent without an evidence column and any basis the server rejected with 422, whose sentence is shown verbatim) → **Kontakte** (CSV, `guessMapping()` recognises `Name/Telefon/Einwilligung/Termin` and English headers, E.164 preview with duplicates and invalid rows, then the server's scrub result "n entfernt: Werbewiderspruch" — the only way forward) → **Skript** (briefing, the profile's allowed tools from the Werkzeuge page, locked opt-out sentence) → **Zeitfenster & Tempo** (days, window, quiet hours, concurrency, retries; caller ID is your first number, read-only) → **Prüfen** (summary, the backend check list; Starten only when every check is green and `STARTEN` is typed — decision §11 Phase 1). Detail: live counters (SSE `campaign.progress` → `['voice','campaign',id]`), contacts with the backend's `skip_reason` verbatim, pause/resume/stop with confirm, masked CSV export. Erinnerungen (F2) settings are read-only with an F2 badge until served.
