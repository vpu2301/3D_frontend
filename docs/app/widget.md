# Website-Widget (FE9 §3)

**App** — route `/telephony/settings/widget`; components `src/pages/telephony/_components/settings/widget/WidgetView.tsx` (`EmbedSnippet`, key list with stats, appearance, features, preview iframe); data `src/lib/api/owner/widget.ts`; namespace `voice-widget`. G3's `api/widget.py` does not exist: keys (`GET/POST /api/widget/keys`, rotate, revoke), settings (`GET/PUT /api/widget/settings`) and stats (`GET /api/widget/stats?key=`) badge on 404 behind one banner. Origins are validated as exact https origins with an optional `*.` subdomain wildcard. The preview iframe mounts the locally built `w.js` against the connected backend with `data-preview="1"`. The embed snippet is `<script src="https://app.3days.ai/w.js" data-site-key="…" integrity="sha384-…" crossorigin="anonymous" async>` (or pinned `w.<version>.js`), with hints for WordPress, Jimdo and IONOS.

**Package** — `packages/widget/src/{widget,lib}.ts`, vanilla TypeScript, no framework, no shared runtime with the app. `npm run build:widget` (vite lib mode, IIFE, es2019, no sourcemap) writes `public/w.js` and `scripts/widget-size.mjs` enforces ≤ 40 KB gzipped, refuses `eval`, and writes `src/content/widget-meta.json` {version, integrity sha384, bytes}. Today: ~21.8 KB raw, ~7.6 KB gzipped. CI builds it before e2e. Shadow DOM styles, no cookies (session id in memory; the only storage is the transcript-e-mail consent, still unused), no third-party scripts. Config from the tag: `data-site-key`, `data-api` (defaults to the script origin), `data-lang`, `data-preview`.

Flows against `/w/*` (site key in body and `X-Site-Key`): `GET /w/session` (business name, phone, features, langs, disclosure, appearance), `POST /w/chat` SSE (`chunk {delta}`, `source {title,url}` → chips, `done {abstain,text}`, `error`), `GET /w/slots?days=7` (30 s TTL, grouped by day, past dropped), `POST /w/book`, `POST /w/message` (fields from settings), `POST /w/callback`, `tel:` for "Jetzt anrufen". The disclosure line is always visible in the panel; abstention renders "Das weiß ich nicht — soll ich eine Nachricht aufnehmen?" with a button into the message form; 429 and 403 render polite text (403 shows a one-click acknowledgement until the CAPTCHA provider is decided). Language switch DE/EN/UK, `role=dialog`/`log`, Esc closes, reduced motion respected. The widget renders nothing the server did not return (e2e: an owner-data prompt shows only the server's refusal).

Tests: `src/test/widget/lib.test.ts` (E.164 hints, slot grouping, SSE parser, language pick), `e2e/fe9.spec.ts` on `public/widget-fixture.html` (disclosure → answer with source chip → abstention → booking with E.164 hint → callback → no cookies → axe), plus the settings page and the snippet's integrity.
