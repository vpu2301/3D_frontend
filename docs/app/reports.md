# Berichte & Kennzahlen (FE8 §1)

Route `/telephony/reports`. Components `src/pages/telephony/_components/reports/*` (`ReportsView`, `ReportView` with `ReportSection`, `SentimentSplit`, `MethodTag`, `ReportPreferences`, `KpiTiles`); data `src/lib/api/owner/reports.ts`; namespace `voice-reports`.

G2's report API does not exist yet. `useReport(period, date)` asks `GET /api/voice/reports?period=daily|weekly&date=` first; on 404 it renders `computeReport()` in the browser from the loaded history, messages, receptionist stats (sentiment), today's costs and the unanswered clusters — every metric then carries `method: "estimated"`, `MethodTag` prints "geschätzt", and the page wears the computed badge with `data-source="browser"`. A server report is shown as delivered (`rendered_by: "server"`) and never re-computed. Sections: Anrufe (ein/aus, angenommen/verpasst/außerhalb), Termine, Rückrufe (masked numbers), Weiterleitungen & Notfälle, Stimmung (split bar), Unbeantwortete Fragen (link to Wissen), Nachfass (E2 badge until the API), Kosten (today only, EUR), "3 Dinge" (top three open queue items, link to Aufmerksamkeit). Collapsible on phones. Archive: a date picker over daily reports; the server list (`period=archive`) fills it (badge until then).

**Zustellung** (`GET/PUT /api/voice/reports/preferences`, `POST /api/voice/reports/test`): channels, time + timezone, weekly day, sections, masking, per-report unsubscribe, "Testbericht jetzt senden" — disabled with a G2 badge until the server stores them.

**Kennzahlen** (`GET /api/voice/kpis?range=7|30` → `{tiles:[{key, value, unit, method, series, label}]}`): answered rate, bookings/day, median time-to-callback (from the browser-local Erledigt timestamps until G2), unanswered-question trend — computed by `computeKpis()` with `method: "estimated"` and small recharts bars; the disclosure rate is never invented and shows a G2 badge until the server reports it. Vertical labels arrive as `label` on the tile when a G1 pack is applied.
